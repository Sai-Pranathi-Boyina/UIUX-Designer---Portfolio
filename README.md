# Sai Pranathi Boyina · 3D Interactive Product Designer Portfolio

> 🌐 **Live Portfolio:** [https://sai-pranathi-boyina.github.io/UIUX-Designer---Portfolio/](https://sai-pranathi-boyina.github.io/UIUX-Designer---Portfolio/)

An immersive, spatial 3D portfolio for **Sai Pranathi Boyina** — Product Designer specializing in UI/UX architecture, enterprise Figma Design Systems, and interactive WebGL experiences. Built with Three.js, live in-model 2D canvas texture streaming, and Blender 3D kinematics.

---

## 🌟 Interactive Zones & Experience

The portfolio transforms a traditional design CV into an interactive 3D studio environment:

| Section | Focus Prop | Experience & Functionality |
| :--- | :--- | :--- |
| **00 · Room (Home)** | Whole Studio | Cinematic fly-in camera overview with animated character and atmospheric studio lighting. |
| **01 · Skills** | 16" Laptop Screen | In-model interactive screen with tab switching across *Core Skills*, *Design Systems*, *Tools*, and *Engineering Sync*. |
| **02 · Experience** | Lanyard Badges Noticeboard | Interactive 3D ID badges with card-flip animations detailing product design roles, startup milestones, and leadership. |
| **03 · Projects** | 27" Desktop Monitor | Interactive multi-card carousel with live pagination pills, verified design metrics, and case study links. |
| **04 · Education** | Cupboard Wardrobe | Realistic wardrobe door hinge animations revealing academic credentials (B.Tech, Intermediate, SSC). |
| **05 · Contact** | Desk Smartphone | Portrait smartphone lock screen with live clock, direct email actions, 1-click CV download, and verified links. |

---

## 🛠️ Technology Stack

- **Three.js (WebGL)**: Real-time 3D rendering, PBR materials, orbit controls, and raycasting.
- **TWEEN.js**: Smooth cubic easing camera fly-throughs and cupboard kinematics.
- **HTML5 Canvas 2D Texture Engine**: High-fidelity dynamic canvas rendering projected onto 3D screen geometries.
- **Blender 3D**: Optimized low-poly home office environment and character modeling.
- **Vanilla Modern JS / CSS**: Zero heavyweight frontend dependencies, instant load times, and responsive viewports.

## 🚀 Local Development & Preview

To run and preview the portfolio locally:

```bash
# Clone the repository
git clone https://github.com/Sai-Pranathi-Boyina/UIUX-Designer---Portfolio.git

# Navigate into the project directory
cd UIUX-Designer---Portfolio

# Launch a lightweight static server
python3 -m http.server 8000
```

Open `http://localhost:8000/` in your browser.
